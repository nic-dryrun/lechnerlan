# Lechner LAN Wallpapers

Desktop wallpapers (1920×1080) for the Lechner LAN party computers, themed around the seven games in rotation: Call of Duty, Halo, Flatout 2, StarCraft, Counter Strike, Age of Empires, and Star Wars.

**Live gallery:** https://nic-dryrun.github.io/lechner-lan/

## Contents

- `images/` — full-resolution PNG wallpapers
- `jpg/` — 1920×1080 JPG copies (smaller filesize, easier to download)
- `thumbs/` — gallery thumbnails (640×360 JPG)
- `lechner-lan-wallpapers.zip` — all JPGs in a single download
- `gallery.json` — manifest used by the gallery page
- `index.html` — the gallery page
